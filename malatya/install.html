تطبيق على جهازك

أيقونة على الشاشة الرئيسية أو قائمة البرامج، تفتح بلا شريط متصفّح، وتعمل صفحاتها حين تنقطع الشبكة.

صلاحية التعديل

تضيف وتعدّل وتحذف وتنشر من داخل المنظومة، فتظهر النتيجة على الموقع خلال دقائق.

استقلال كامل

لا تنتظر أحداً: التحديث اليومي يعمل وحده، وأنت تتدخّل متى شئت وتتراجع متى شئت.

الجزء الأول — التثبيت كتطبيق

1 ثبّت الآن

إن كان جهازك يدعم التثبيت المباشر سيظهر الزرّ. وإلّا فاتبع خطوات نظامك أدناه.

جارٍ الفحص…
  1. افتح jmahery.com/malatya/ في Chrome.
  2. اضغط النقاط الثلاث ⋮ أعلى اليمين.
  3. اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
  4. ستظهر أيقونة المنظومة مع بقية تطبيقاتك.
  1. افتح الموقع في Safari — لا يعمل التثبيت من Chrome على الآيفون.
  2. اضغط زرّ المشاركة ⬆︎ في شريط الأسفل.
  3. مرّر واختر «إضافة إلى الشاشة الرئيسية».
  4. اضغط «إضافة». تظهر الأيقونة على الشاشة الرئيسية.

آبل لا تتيح زرّ تثبيت داخل الصفحة، لذلك هذه هي الطريقة الوحيدة على أجهزتها.

  1. افتح الموقع في Chrome أو Edge.
  2. في شريط العنوان تظهر أيقونة تثبيت (شاشة صغيرة بسهم) — اضغطها.
  3. أو: القائمة ⋮ ← «تثبيت منظومة ملاطيا».
  4. تصير المنظومة برنامجاً في قائمة ابدأ، ويمكن تثبيتها في شريط المهامّ.
  1. Chrome أو Edge: القائمة ⋮ ← «تثبيت…».
  2. Safari: ملف ← «إضافة إلى Dock».

الجزء الثاني — صلاحية التعديل

المنظومة تُنشر من مستودعك على GitHub. لتعدّل بنفسك تحتاج رمز وصول تصنعه أنت. الرمز يُحفظ في متصفّح هذا الجهاز فقط، ولا يمرّ بأي طرف ثالث. إن ضاع الجهاز: ألغِ الرمز من GitHub فيصير بلا قيمة فوراً.

2 أنشئ الرمز

  1. افتح صفحة إنشاء الرمز على GitHub ↗ (سجّل الدخول إن طُلب).
  2. Token name: اكتب malatya-admin.
  3. Expiration: اختر مدّة تناسبك — ٩٠ يوماً معقولة. عند انتهائها تُنشئ رمزاً جديداً بالخطوات نفسها.
  4. Repository access: اختر Only select repositories ثم اختر claude-guide وحده.
    لا تختر «All repositories» — لا داعي أن يفتح الرمز ما لا يحتاجه.
  5. Permissions → Repository permissions، اضبط اثنين فقط:
    • Contents → Read and write — ليحفظ تعديلاتك.
    • Actions → Read and write — ليشغّل التحديث والنشر.
    اترك الباقي على No access.
  6. اضغط Generate token، ثم انسخ الرمز فوراً — لا يظهر ثانيةً.

3 الصقه في المنظومة

  1. افتح لوحة الإدارة.
  2. الصق الرمز في الحقل واضغط «اتّصل».
  3. إن ظهر «متّصلة» فقد انتهيت. وإن ظهر خطأ فالسبب في ٩٥٪ من الحالات أحد اثنين: الرمز لم يشمل مستودع claude-guide، أو صلاحية Contents بقيت على القراءة فقط.

أسئلة تتكرّر

  • هل يرى أحد رمزي؟ لا. يُحفظ في تخزين المتصفّح على جهازك، ويُرسَل إلى GitHub وحده عند كل عملية. من يفتح صفحة الإدارة بلا رمز لا يستطيع شيئاً.
  • ماذا لو انتهت صلاحية الرمز؟ ستظهر رسالة «الرمز غير صالح أو انتهت صلاحيته». أنشئ رمزاً جديداً بالخطوات نفسها والصقه — لا شيء آخر يتغيّر.
  • ماذا لو ثبّتّه على الهاتف والحاسوب؟ لا مانع. كل جهاز يحمل رمزه، ويمكن إنشاء رمز لكل جهاز على حدة لتلغي واحداً دون أن تعطّل الآخر.
  • هل التطبيق نسخة منفصلة؟ لا — هو الموقع نفسه في إطار تطبيق. ما تنشره يظهر في الاثنين.
  • أرى بيانات قديمة. اضغط «امسح الذاكرة المخزَّنة» أعلاه. المنظومة لا تعرض بيانات مخزَّنة إلّا حين تنقطع الشبكة، وتقول لك ذلك صراحةً.
